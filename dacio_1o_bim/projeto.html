    - AND: Só retorna 1 se todas as entradas forem 1.

    - NAND: É o contrário da AND. Só retorna 0 quando ambas entradas são 1.

    - OR: Retorna 1 se pelo menos uma entrada for 1.

    - NOR: É o contrário da OR. Só retorna 1 quando ambos são 0.

    - NOT: Inverte o valor.

    - XOR: Retorna 1 quando as entradas são diferentes.

    - XNOR: É o contrário da XOR. Retorna 1 quando as entradas são iguais.

• CPU (Unidade Central de Processamento):

A CPU é o “cérebro” do computador. Ela é responsável por executar instruções,
realizar cálculos matemáticos e tomar decisões lógicas.
Todo programa, jogo ou aplicativo só funciona porque a CPU interpreta
e processa comandos continuamente.

• Memória (RAM e Armazenamento):

A memória é onde os dados e programas são guardados. RAM: memória temporária, usada enquanto o computador está ligado. É rápida, mas perde os dados ao desligar. Armazenamento (HD ou SSD): guarda dados permanentemente, como arquivos, sistemas e programas.

• BARRAMENTO :

Os barramentos são os canais de comunicação do computador.
Eles conectam CPU, memória e outros componentes, permitindo a troca de dados,
endereços e sinais de controle dentro do sistema.
